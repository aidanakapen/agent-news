# Сводка ведомств — агент-помощник редактора

Агент три раза в день (в 9:00, 14:00 и 19:00 по Астане) читает официальные Telegram-каналы правительства и министерств Казахстана. Он отбирает важное для обычных людей и готовит черновики новостей на русском и казахском языках. Редактор проверяет их на отдельном сайте, правит и утверждает каждую языковую версию. Затем копирует заголовок и текст в WordPress.

Агент сам ничего не публикует. Требования описаны в [agent-news.md](agent-news.md).

## Как это устроено

| Часть | Где работает | Что делает |
| --- | --- | --- |
| Сбор и черновики | GitHub Actions, [.github/workflows/collect.yml](.github/workflows/collect.yml) | По расписанию читает `t.me/s/<канал>`, отбирает новости и пишет черновики через Claude API |
| Хранилище | Ветка `data` этого репозитория | Выпуски `issues/*.json`, список каналов `channels.json`, состояние сбора `state.json` |
| Редактор | GitHub Pages, [docs/index.html](docs/index.html) | Дайджест: правка, статусы RU/KZ, копирование, список каналов, ручной запуск сбора |

Сервер не нужен. Платить нужно только за Claude API.

## Настройка (один раз, около 20 минут)

### 1. Создать репозиторий и загрузить проект

1. Создайте репозиторий на github.com (у нас это `aidanakapen/agent-news`).
2. Загрузите в него все файлы этой папки, кроме `node_modules`.

**Публичный или приватный?** На бесплатном тарифе GitHub Pages работает только у публичных репозиториев. Тогда черновики в ветке `data` сможет увидеть любой, кто найдёт репозиторий. Это пересказы открытых постов госорганов, но если это нежелательно, нужен тариф GitHub Pro (4 $ в месяц) и приватный репозиторий.

### 2. Добавить ключ Claude API

1. Получите ключ на [console.anthropic.com](https://console.anthropic.com) → API Keys и пополните баланс.
2. В репозитории откройте **Settings → Secrets and variables → Actions → New repository secret**.
3. Name: `ANTHROPIC_API_KEY`, Secret: ваш ключ.

### 3. Включить сайт-редактор

**Settings → Pages → Build and deployment**: Source — *Deploy from a branch*, Branch — `main`, папка `/docs`. Через минуту появится адрес вида `https://aidanakapen.github.io/agent-news/`.

### 4. Первый запуск

**Actions → «Сбор новостей» → Run workflow**. Через 3–10 минут в репозитории появится ветка `data` с первым выпуском.

### 5. Токен для редактора

Сайт сохраняет правки прямо в репозиторий, поэтому ему нужен токен GitHub.

1. [github.com/settings/personal-access-tokens/new](https://github.com/settings/personal-access-tokens/new) → *Fine-grained token*.
2. Repository access → *Only select repositories* → ваш репозиторий.
3. Permissions → Repository permissions: **Contents — Read and write**, **Actions — Read and write**.
4. Откройте сайт-редактор → **Настройки**, вставьте токен и нажмите «Сохранить и загрузить».

Токен хранится только в браузере редактора и никуда, кроме GitHub, не отправляется.

## Работа редактора

1. Откройте сайт. Сверху показан последний выпуск, срочные сообщения о ЧС стоят первыми и отмечены красной полосой.
2. Переключайте **RU / KZ**. Точка у языка показывает статус: серая — ждёт проверки, зелёная — утверждено, перечёркнутая — отклонено.
3. Сверьте черновик с исходным постом (ссылка под текстом). Правьте заголовок и текст прямо на странице, правки сохраняются сами через пару секунд.
4. Пометка **«Перевод агента»** значит, что ведомство не публиковало версию на этом языке и её перевёл агент. Такие версии проверяйте внимательнее.
5. Нажмите **«Утвердить RU»** или **«Отклонить»**. Каждая языковая версия утверждается отдельно.
6. **«Скопировать заголовок»** и **«Скопировать текст»** копируют поля для WordPress по отдельности. К тексту автоматически добавляется строка с источником: ведомство, дата, ссылка на пост.

Список каналов меняется в **Настройках**: включить, выключить, убрать или добавить канал.

## Мокап без ключа

Пока секрет `ANTHROPIC_API_KEY` не добавлен, агент работает в режиме мокапа. Он собирает настоящие посты, отбирает их по ключевым словам ([agent/mock.mjs](agent/mock.mjs)) и кладёт тексты постов в редактор без обработки, с пометкой «Мокап». Последний обработанный пост при этом не запоминается, поэтому после добавления ключа Claude заново обработает те же посты.

Сайт без токена открывается в режиме просмотра: выпуски видны, но правки и статусы не сохраняются.

## Модель и стоимость

По умолчанию черновики пишет `claude-opus-5`. Примерный расход — около 1 $ за выпуск, то есть около 3 $ в день (зависит от числа постов). Чтобы снизить расход примерно вдвое, создайте в **Settings → Secrets and variables → Actions → Variables** переменную `CLAUDE_MODEL` со значением `claude-sonnet-5`.

## Расписание

Время задано в UTC в [collect.yml](.github/workflows/collect.yml): `0 4,9,14 * * *` — это 9:00, 14:00 и 19:00 по Астане. GitHub иногда запускает задачи с опозданием на 5–20 минут. Если в репозитории 60 дней не было коммитов, GitHub приостанавливает расписание. Здесь агент коммитит каждый выпуск, поэтому этого не случится.

## Для разработчика

```bash
npm install
node collector/collect.mjs KZgovernment,qr_tjm   # посмотреть посты за сутки
ANTHROPIC_API_KEY=... node agent/run.mjs          # собрать выпуск в ./store
```

| Файл | Назначение |
| --- | --- |
| `collector/collect.mjs` | Чтение веб-просмотра Telegram-каналов |
| `agent/prompts.mjs` | Правила отбора и требования к текстам (из PRD) |
| `agent/run.mjs` | Выпуск: сбор → отбор → черновики RU/KZ → `issues/<дата-время>.json` |
| `config/channels.json` | Начальный список каналов (копируется в ветку `data` при первом запуске) |
| `docs/index.html` | Сайт-редактор |
